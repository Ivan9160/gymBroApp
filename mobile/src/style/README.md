# Split account styles

The original style file has been split by responsibility without deleting style definitions.

- `theme.ts` — colors, dimensions, breakpoints.
- `accountPageStyles.ts` — account page.
- `modalStyles.ts` — finish workout modal.
- `swipeStyles.ts` — swipeable set item.
- `appShellStyles.ts` — shared app shell.
- `guestStyles.ts` — guest landing page.
- `formPageStyles.ts` — profile forms.
- `loadingStyles.ts` — loading UI.
- `creatorStyles.ts` — creator styles.
- `historyStyles.ts` — workout history.
- `detailsStyles.ts` — workout details.
- `contentStyles.ts` — shared content page.
- `responsiveStyles.ts` — responsive overrides.
- `exerciseCreatorStyles.ts` — direct exercise creator styles.
- `platformStyles.ts` — platform-specific equivalents.
- `styles.ts` — backwards-compatible combined `styles` export.
- `responsiveHelpers.ts` — responsive helper functions.
- `index.ts` — barrel exports.

The original combined `styles` object is preserved in `styles.ts`.
